# PRODIGY_ML_01

## House Price Prediction using Linear Regression

This project is Task 01 of my Machine Learning Internship at Prodigy InfoTech.

### Objective

To implement a Linear Regression model to predict house prices based on:

- Living area (square footage)
- Number of bedrooms
- Number of full bathrooms

### Dataset

The project uses the Kaggle House Prices: Advanced Regression Techniques dataset.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- Jupyter Notebook

### Machine Learning Model

Multiple Linear Regression

### Steps Performed

1. Loaded the dataset
2. Selected relevant features
3. Checked for missing values
4. Performed basic statistical analysis
5. Visualized feature relationships
6. Split the data into training and testing sets
7. Trained the Linear Regression model
8. Generated predictions
9. Evaluated the model using MAE, MSE, RMSE, and R² Score
10. Compared actual and predicted house prices
11. Predicted the price of a new house

### Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score
